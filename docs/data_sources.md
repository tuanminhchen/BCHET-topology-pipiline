# Data sources

Raw protein structures:
- AlphaFold Protein Structure Database: https://alphafold.ebi.ac.uk/

Designed / synthetic proteins:
- RCSB Protein Data Bank: https://www.rcsb.org/

Genome / protein annotation:
- Ensembl: https://www.ensembl.org/
- UniProt: https://www.uniprot.org/

Redistribution note:
Raw AlphaFold proteome archives and PDB coordinate files are large and publicly available; therefore they are not redistributed in this repository.
This repository provides source lists, processed tables, and scripts needed to reproduce the BCHET analyses at the level of summary statistics and lightweight figure generation.
